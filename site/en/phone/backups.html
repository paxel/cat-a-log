Where your catalogs are kept safe: what the phone backs up by itself, where the full copies land, when the last one was written, and a button to write one now.

Automatic

A full copy of every catalog, photos included, is written to the backup folder whenever the app is left after changes. On Android the folder is granted once through the picker.

Restore

Restore lives in Manage catalogs: the backups of the install before this one, one row per catalog, ticked. Restore brings each back as its own catalog; Pick files adds backups kept anywhere else.

Archive

Old data costs space, above all the photos every synced device carries. The archive writes deceased cats and empty homes into a file you keep and deletes them.
