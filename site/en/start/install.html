The phone app runs on Android and iPhone, the desk app on Linux, Windows and macOS. Every channel below carries the same release; pick the one you already use. Nothing to sign up for, nothing to pay.

Android

  • Google Play

    Install from the Play listing. Play updates the app on its own.

  • F-Droid

    Add the repository https://paxel.github.io/fdroid/repo to the F-Droid app, then install cat(a)log from it. F-Droid updates it with the rest of your apps.

    The repository is called "paxel's apps"; F-Droid shows its fingerprint when you add it and remembers it.

  • The APK

    Download the file ending in arm64-v8a.apk from the releases, open it and allow the installation when the phone asks. An APK does not update itself: come back for the next release, or add the F-Droid repository instead.

Android: the shared folder needs a folder the phone can write, a cloud client's folder or a USB stick; the app asks for it once.

iPhone and iPad

  • App Store

    Install from the App Store listing. The App Store updates the app on its own.

  • TestFlight

    The beta of the next release runs through Apple's TestFlight. Ask for an invitation.

Linux

  • Homebrew

    brew install paxel/tap/catlog

    The app lands in the application menu right after the install. brew upgrade updates it.

  • deb

    Download the .deb for your machine (x86_64 or arm64) from the releases and install it with your package tool. It does not update itself.

  • AppImage

    Download the .AppImage, make it executable, run it. It registers its own menu entry and icon. It does not update itself.

  • tar.gz

    Download the tar.gz, unpack it anywhere, run catlog. For a machine without a package manager.

Windows

  • Scoop

    scoop bucket add paxel https://github.com/paxel/scoop-bucket
scoop install catlog

    scoop update catlog updates it.

  • zip

    Download the file ending in windows-x86_64.zip, unpack it anywhere, double-click catlog.exe. It does not update itself.

macOS

  • Homebrew

    brew install --cask paxel/tap/catlog

    brew upgrade updates it.

  • dmg

    Download the .dmg for your Mac (arm64 for Apple silicon, x86_64 for Intel), drag the app into Applications. The first time, right-click the app and choose "Open": it is not signed with Apple, so the Mac asks once.

After the install

The app opens with a short tour and asks for your name, the author every change is recorded under. Then the first catalog is yours: the first ten minutes.
