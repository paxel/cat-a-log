Zwei Regeln tragen das Telefon: ein Tipp ist die Hauptaktion, ein langer Druck die zweite. Der Schreibtisch hört auf Tasten und den Rechtsklick.

Auf dem Telefon

GesteWas sie tut
TippenÖffnet das Ding; auf einem Kästchen hakt es ab. Ein Tipp öffnet nie ein Menü.
HaltenDas Menü, oder der Editor, wenn es nur eines zu tun gibt. Alles, was sich halten lässt, trägt das Katzenohr in seiner Ecke.
Nach links wischen auf einer NotizDie nächste Notiz.
Nach rechts wischen auf einer NotizRäumt die Neuigkeiten weg; Fehler bleiben.
Halten auf der KarteTrägt eine Sichtung oder einen Aushang für eine gewählte Katze ein.
Halten auf einem Pin oder einem SpurpunktSein Menü: Verlauf, Korrektur, Entfernen, Aushang abgenommen.
Kneifen und Ziehen auf dem PlakatRahmt ein Foto ein.

Nichts schiebt sich von unten herein; jedes Menü öffnet dort, wo der Finger ist. Eine Auswahl unter mehreren ist eine Liste von Optionen, nie eine Reihe von Pillen.

Auf dem Schreibtisch

TasteWas sie tut
Strg 1 bis Strg 7Home, Katzen, Kolonien, Karte, Agenda, Tierarzt, Familie.
Pfeile, EnterEine Tabelle entlanglaufen, die markierte Zeile als Karte öffnen.
Strg-Klick, Umschalt-KlickMehrere Zeilen markieren.
EscapeSchließt den obersten Dialog.
RechtsklickDasselbe Menü wie das ⋮ neben einer Zeile, einer Karte, einem Pin oder einem Foto.
Umschalt-Ziehen auf der KarteEin Kasten zum Hineinzoomen.
Die Titelleiste einer Karte ziehen, ihre UnterkanteBewegt sie, vergrößert sie.
