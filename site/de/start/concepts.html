cat(a)log hat einen kleinen Wortschatz und bleibt dabei. Das sind die Wörter, die dir am ersten Tag begegnen; das Glossar hat jedes.

Katalog

Alles, was eine Arbeit umfasst: ihre Katzen, ihre Orte, ihre Felder, ihre Fotos und die Partner, mit denen sie abgleicht. Ein Gerät kann mehrere Kataloge halten, und nichts wandert zwischen ihnen, so bleiben Berlin und Paris getrennt. Ein Katalog ist jeweils offen; sein Name ist der Titel der Startseite.

Kolonie

Ein Ort, an dem Katzen leben, mit Adresse und einer verantwortlichen Person: dein Zuhause, eine Pflegestelle, ein Tierheim, ein Hof, eine Tierarztpraxis, das Zuhause, in das eine Katze vermittelt wurde. Die App sagt "Zuhause", wo es passt. Im Haustiermodus heißt es "Haushalt"; die Sache ist dieselbe.

Katze

Ein Tier: ein Name, Fotos, Felder, deren Werte sich mit der Zeit ändern, und die Historie von alldem. Wo sie lebt, ist auch ein Feld, ein Umzug also eine datierte Änderung wie jede andere.

Streuner

Eine Katze, die gerade in keiner Kolonie lebt: eine Fundkatze, eine entlaufene, eine, die man nur vom Aushang kennt. Keine Art von Katze, sondern ein Zustand; er endet mit einem Umzug in eine Kolonie. Streuner werden über Positionen auf der Karte verfolgt statt über eine Adresse.

Feld

Eine typisierte Eigenschaft an Katzen und Kolonien: Text, Ja oder Nein, ein Datum, eine Zahl, ein Messwert mit Einheit, eine Auswahl, ein Ort, eine ID, ein Verweis auf eine andere Katze. Die Starterfelder kommen mit der App, eigene legst du auf jeder Seite an. Jeder Wert trägt ein Datum und den Autor, der ihn schrieb, und jede Änderung bleibt erhalten.

Autor

Der Name, den ein Gerät trägt. Jede Änderung wird einem Autor zugeschrieben; Konten gibt es nicht. Partner sehen einen kurzen Schlüsselcode neben deinem Namen, damit niemand in deinem Namen schreiben kann.

Moment

Ein Punkt, zu dem der Katalog zurückkehren kann. Einer wird vor allem festgehalten, was viel auf einmal ändert, einem Import, einem Abgleich, einem Zusammenführen, einem Archivieren, und einen kannst du selbst markieren. Zurückgehen entfernt alles danach, nachdem es in eine Datei geschrieben wurde.

Gemeinsamer Ordner, Bündel, persönlich

Drei Wege, dein Wissen zu einem Partner zu bringen, keiner über einen Server. Ein gemeinsamer Ordner ist ein Ordner, den beide Geräte sehen, auf einem Cloud-Client oder einem USB-Stick; jeder Abgleich schreibt deine Änderungen hinein und liest die der anderen. Ein Bündel ist eine .catsync-Datei mit allem, was ein Gerät weiß, verschickt über jeden Messenger. Persönlich verbindet zwei Geräte im selben Raum über WLAN, verschlüsselt, nachdem eines den Code des anderen gescannt hat.
