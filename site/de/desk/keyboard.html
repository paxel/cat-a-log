Der Schreibtisch ist ohne Maus benutzbar. Das sind die Tasten, auf die er hört.

TasteWas sie tut
Strg 1 bis Strg 7Home, Katzen, Kolonien, Karte, Agenda, Tierarzt, Familie
PfeileDie Zeilen einer Tabelle entlanglaufen
EnterDie markierte Zeile als Karte auf dem Schreibtisch öffnen
Strg-Klick, Umschalt-KlickMehrere Zeilen markieren, eine mehr oder einen Bereich
EscapeDen obersten Dialog schließen, oder das Menü
Umschalt-Ziehen auf der KarteEinen Kasten ziehen und hineinzoomen
Tippen in einer TabelleGeht ins Suchfeld

Ein Rechtsklick auf eine Zeile, eine Karte, einen Pin oder ein Foto öffnet dasselbe Menü wie das ⋮ daneben.
