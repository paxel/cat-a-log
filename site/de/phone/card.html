Die Karte einer Katze ist das eine Blatt, das du jemandem gibst: Foto, die Werte, die du wählst, die IDs als Codes.

Was draufsteht

Die Chips oben wählen die Felder, die erscheinen; die Wahl wird gemerkt. Eine ID kann als Text, QR-Code oder Strichcode gedruckt werden, und aus einer Position wird ein QR-Code, der eine Karte öffnet, plus ein kurzer Plus Code. Das Alter steht neben dem Geburtsdatum; eine verstorbene Katze zeigt das erreichte Alter.

Teilen

Als Bild teilen, als PDF teilen, drucken: die drei in der Leiste. Das Bild geht an jeden Messenger, das PDF an eine Mail oder einen Drucker. Ein Zuhause hat auch eine Karte, mit den Katzen, die dort leben.
